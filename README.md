# MaxTasks

A self-hosted, API-first task manager for web and Android, built with React, Go, and PostgreSQL. MaxTasks aims to provide an installable PWA, a focused Google Tasks-inspired UI, documented APIs, Docker deployment, automated tests, CI/CD, encrypted backups, and a live demo.

- [Project plan](docs/PROJECT_PLAN.md) — vision, scope, milestones, architecture, and delivery workflow

## Current status

The project is currently in the documentation and planning stage. The next milestone is the technical foundation: a Dockerized Go API, React frontend, and PostgreSQL database.
